# KiwiDesk for Claude Code

The Claude Code plugin marketplace for
[KiwiDesk](https://kiwidesk.kiwicanopy.com), the tiling window manager
for macOS. Its one plugin connects Claude Code to KiwiDesk's own MCP
server, so you can set up and control KiwiDesk by asking Claude.

```sh
/plugin marketplace add KiwiCanopy/KiwiDesk-Claude
/plugin install kiwidesk@kiwidesk
```

The plugin needs KiwiDesk 3.0 or later; see
[`kiwidesk/README.md`](kiwidesk/README.md).

This repository is copied from
[KiwiCanopy/KiwiDesk](https://github.com/KiwiCanopy/KiwiDesk)'s
`plugins/` folder at each release — please open issues and pull
requests there.
